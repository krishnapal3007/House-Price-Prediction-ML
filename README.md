# 🏠 House Price Prediction using Linear Regression

## 📌 Task
Prodigy InfoTech Machine Learning Internship - Task 01

## 🎯 Objective
Build a Linear Regression model to predict house prices using:
- Ground Living Area (GrLivArea)
- Number of Bedrooms (BedroomAbvGr)
- Number of Full Bathrooms (FullBath)

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 📂 Dataset
House Prices: Advanced Regression Techniques (Kaggle)

## 🤖 Machine Learning Model
Linear Regression

## 📊 Evaluation Metrics
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## 📈 Results
The model was trained successfully and evaluated using standard regression metrics. It predicts house prices based on selected house features.
