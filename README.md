# 🏠 House Price Prediction using Linear Regression

## 📌 Overview
This project implements a **Linear Regression** model to predict house prices based on features such as area, number of bedrooms, and bathrooms. The goal is to build a predictive model using supervised machine learning techniques.

This project was completed as **Task-01** of the **Prodigy InfoTech Machine Learning Internship**.

---

## 🚀 Features
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Feature selection
- Train-Test Split
- Linear Regression Model
- Model Evaluation
- Price Prediction

---

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

---

## 📂 Dataset
House Prices - Advanced Regression Techniques (Kaggle)

https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques

---

## 📊 Machine Learning Model
- Algorithm: **Linear Regression**
- Type: **Supervised Learning**

---

## 📈 Results
The Linear Regression model was trained to predict house prices using the provided dataset. The model demonstrates the application of regression techniques for real-world price prediction problems.
